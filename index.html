Privacy Policy

Last updated: April 2026

1. Overview

AI Product Description is a browser extension that generates product descriptions, titles, and SEO keywords from product images using AI.

2. Data We Process

User-provided content:

  • Product images (uploaded or screenshots)
  • Optional text inputs

Local data (stored in browser):

  • Language settings
  • Tone preferences

This data never leaves the user's device unless required for generation.

3. How Data Is Used

Data is used only to generate product descriptions when the user explicitly requests it.

4. Third-Party Services

We use AI APIs (e.g., OpenAI) to process content and generate results.

5. Data Storage

  • We do not store user images or generated content
  • No browsing history is collected

6. Data Sharing

We do not sell or share user data with third parties.

7. Permissions Usage

  • activeTab — capture screenshots
  • storage — save preferences
  • scripting — enable capture functionality
  • sidePanel — display UI

8. User Control

All actions are user-initiated. No background data collection.
