Privacy Policy

AI Product Description

Last updated: April 2026

This extension does not collect or store personal data. All processing is performed only when you explicitly use the extension.

1. Overview

AI Product Description is a browser extension designed to generate product descriptions, titles, and SEO keywords from product images using artificial intelligence.

2. Data We Process

User-provided content:

  • Product images (uploaded or captured screenshots)
  • Optional text inputs (e.g., product details)

Local data (stored in your browser):

  • Selected language
  • Tone preferences
  • Basic usage settings

This data is used only to provide the functionality of the extension.

3. How Data Is Used

Your data is processed only when you actively use the extension, such as when clicking "Generate description".

  • No background data collection
  • No tracking
  • No behavioral profiling

4. Third-Party Services

To generate AI content, user-provided data may be sent securely to external services such as:

  • AI APIs (e.g., OpenAI)

These services process the data only to generate results and do not have access to your browsing activity.

5. Data Storage

  • We do not store user images or generated content
  • We do not collect browsing history
  • We do not maintain user accounts

6. Data Sharing

We do not sell, rent, or share user data with third parties.

7. Permissions Usage

  • activeTab — capture screenshots on user request
  • storage — save user preferences locally
  • scripting — enable screenshot capture functionality
  • sidePanel — display extension interface

8. Data Security

We implement reasonable technical measures to protect data during processing and transmission.

9. User Control

  • You control what data is provided
  • You can stop using the extension at any time

10. Children's Privacy

This extension is not intended for children under 13.

11. Changes to This Policy

We may update this policy from time to time. Changes will be reflected by updating the "Last updated" date.
