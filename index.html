Privacy Policy

AI Product Description

Last updated: April 2026

This extension processes user-provided content only to generate product descriptions. No personal data is stored.

1. Overview

AI Product Description is a browser extension that generates product descriptions, titles, and SEO keywords from product images using artificial intelligence.

2. Information We Process

User-provided content:

  • Product images (uploaded or captured screenshots)
  • Optional text input provided by the user

This content may include visual data from webpages when the user captures a screenshot.

Local data (stored in browser):

  • Language selection
  • Tone preferences
  • Basic usage settings

This data is stored locally on the user's device and is not transmitted externally.

3. How We Use Information

Information is used solely to provide the core functionality of the extension, including:

  • Generating product descriptions
  • Creating titles and SEO keywords

Processing occurs only when the user explicitly interacts with the extension (e.g., clicking "Generate description").

4. Third-Party Services

To generate AI-based content, user-provided data is securely transmitted to third-party services such as:

  • OpenAI API

These services process the data only for the purpose of generating content and do not have access to the user's browsing history.

5. Data Storage

  • We do not store user images or generated content on our servers
  • We do not collect or retain browsing history
  • We do not maintain user accounts

6. Data Sharing

We do not sell or share user data with third parties, except as necessary to provide the core functionality (AI processing).

7. Permissions Usage

  • activeTab — used to capture screenshots when initiated by the user
  • storage — used to store user preferences locally
  • scripting — used to enable screenshot functionality
  • sidePanel — used to display the extension interface

8. Data Security

We use reasonable safeguards to protect data during transmission and processing.

9. User Control

  • All data processing is initiated by the user
  • No background data collection occurs

10. Children's Privacy

This extension is not intended for children under 13.

11. Changes to This Policy

We may update this policy from time to time. Updates will be reflected by the "Last updated" date.
